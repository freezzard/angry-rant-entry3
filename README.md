Entry for [Angry Judge: The Short Rant Contest](https://make.fun/competitions/u-riidzhsn-angry-judge-the-short-rant-contest-b9f46046) on make.fun.

The program in `main.ts` writes one short, funny rant about an everyday
annoyance — the unsubscribe button that needs ten business days to work —
to `/output/entry.txt`. Three sentences, one line, 295 characters.

Run it with Node 22:

```sh
node main.ts
```
